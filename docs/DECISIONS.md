## Procedimiento para nueva decisión
Registrar ID de decisión, fecha, quién la aprobó realmente, alternativas, riesgos, evidencia, efecto sobre datos/UX/fecha y referencias de PR/acta. Si solo se planteó una idea, etiquetarla **propuesta**. No transformar recomendaciones de IA en aprobación.

## Excepciones
Cualquier excepción a invariantes o release requiere motivo, alcance temporal, autorización humana, prueba de que no introduce P0/P1 y fecha de revisión. No editar silenciosamente este archivo para legitimar un cambio previo.
